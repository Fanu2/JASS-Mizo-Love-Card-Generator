# 💕 JASS Mizo Love Card Generator v1.1

A beautiful, lightweight **single-file PySide6 desktop application** for creating personalized romantic cards using Mizo phrases and messages.

The application is designed around a simple workflow:

> **Choose a Mizo romantic phrase → edit it → customize the card → preview → export**

No database, web service, API, AI model, or external project assets are required.

# 🖱️ Quick Phrase Workflow

The phrase system is designed to make card creation fast.

1. Open the application.
2. Choose **All Categories** or a specific category.
3. Optionally type in the phrase filter.
4. Click a phrase.
5. The phrase is inserted into the card text.
6. Edit the wording if desired.
7. Customize the visual design.
8. Export the finished card.

The phrase counter shows how many phrases are currently displayed after category/filter selection.

---

# ✍️ Editing

A selected phrase is **not locked**.

You can edit the inserted Mizo text before exporting the card.

This allows you to:

- Change individual words
- Combine phrases
- Add names
- Add personal messages
- Create longer messages
- Correct or customize wording
- Write completely original Mizo messages

The quick phrases are therefore starting points rather than fixed card text.

# 🛠️ Requirements

- **Python 3.10+**
- **PySide6**

Install PySide6 if necessary:

```powershell
py -m pip install PySide6
```

The project does **not** require:

- PyTorch
- CUDA
- GPU
- Hugging Face
- Ollama
- Internet connection
- Database
- Machine-learning models

This keeps the application lightweight and suitable for a local desktop environment.

# ▶️ Running the Application

Place the Python file in your desired folder.

For example:

```text
C:\Users\singh\Downloads\
    JASS_Mizo_Love_Card_Generator_v1.1.py
```

Open PowerShell:

```powershell
cd C:\Users\singh\Downloads
```

Run:

```powershell
py .\JASS_Mizo_Love_Card_Generator_v1.1.py
```

# 🧩 Design Philosophy

The project follows a simple principle:

> **Make creating a Mizo romantic card as easy as choosing a phrase.**

Instead of requiring users to manually compose every message, the phrase library provides a large collection of ready-to-use expressions.

The user remains in control:

**Phrase → Edit → Design → Preview → Export**
